# Built-in Functions

List of all the functions that is built into Nbcl by default.

## `print`

Print a value.

```nbl
print("Hello, World")
```

## `to_string`

Convert something to a string.

```nbl
to_string(5)
```

## `as_int`

Convert something to an integer.

```nbl
as_int("10")
```

## `as_float`

Convert something to a float.

```nbl
as_float("3")
```

## `type_of`

Get the type of something

```nbl
type_of("Hello, World")
```

## `len`

Get the length of something

```nbl
len("Hello")
```
